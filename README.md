## Project Overview

PDF Cracker Is A Python-Based PDF Password Recovery Tool Designed To Recover Passwords From Encrypted PDF Documents. It Provides A Menu-Driven Interface Allowing Users To Select Between Dictionary-Based And Hash-Based Password Recovery Methods.

Once The Correct Password Has Been Identified, The Script Decrypts The Protected PDF And Produces An Unlocked Output File Named `Cracked.pdf`.

Developed With Simplicity And Practicality In Mind, PDF Cracker Provides A Straightforward Approach To Recovering Access To Password-Protected PDF Documents.

**Key Features:**
- Python 3 Implementation.
- Menu-Driven Console Interface.
- Dictionary-Based Password Recovery.
- Hash-Based Password Recovery.
- Automated PDF Decryption.
- Generates An Unlocked PDF (`Cracked.pdf`).

**Intended Use:** Legitimate Password Recovery, Authorised Security Testing And Educational Purposes.

### USAGE

```bash
python3 pdf-cracker.py topsecret.pdf
```

A Python script file to crack encrypted `.pdf` files using brute force. The script is menu driven and allows the user to choose between a dictionary attack or a hash attack on the specified file. Once the password has been found, it then decrypts the file completely (`Cracked.pdf`).
